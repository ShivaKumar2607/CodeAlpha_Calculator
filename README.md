# CodeAlpha_Calculator

A responsive calculator developed using HTML, CSS, and JavaScript as part of my CodeAlpha Frontend Development Internship.

## 📌 Description

This project is a basic web-based calculator that performs arithmetic calculations through an interactive user interface.

The calculator provides buttons for numbers, decimal values, addition, subtraction, multiplication, division, percentage, clear, delete, and equals operations.

## ✨ Features

- Basic arithmetic operations
  - Addition (+)
  - Subtraction (−)
  - Multiplication (×)
  - Division (÷)
- Percentage (%) calculation
- Decimal number support
- Clear (AC) button
- Delete (⌫) button
- Error handling for invalid calculations
- Keyboard support
- Responsive and user-friendly interface
- Interactive button hover and click effects

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Start performing calculations.

## 🎮 How to Use
- Click the number buttons to enter values.
- Select an arithmetic operator.
- Enter the next number.
- Click = to calculate the result.
- Use AC to clear the display.
- Use ⌫ to delete the last entered character.
- Use % for percentage calculations.
  
## ⌨️ Keyboard Support

The calculator also supports keyboard input.

- Numbers (0 - 9)
- Addition (+)
- Subtraction (−)
- Multiplication (*)
- Division (/)
- Enter or = → Calculate
- Backspace → Delete
- Escape → Clear
